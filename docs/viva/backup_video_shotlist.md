# Backup Video Shotlist

Pre-record this flow if live demo is risky. Total recording: ~6 minutes.

## Shot 1 — Login Flow (30s)
- Screen record the login page
- Type credentials, click Sign In
- Show the redirect to `/teacher`

## Shot 2 — Capture + RTSP (60s)
- Navigate to `/capture`
- Select RTSP source
- Click Start → show live feed for 10s
- Show connection badge green
- Show a person walking into frame

## Shot 3 — Student Marked Present (45s)
- Split screen: capture feed + `/teacher` roster
- Wait for re-ID cycle (~30s)
- Show the student chip transition ABSENT → PRESENT

## Shot 4 — Exam Mode + Phone Flag (45s)
- Switch to exam mode in settings
- Hold a phone in view
- Show the proctor flag appearing
- Navigate to `/proctor` → show the flag in the queue

## Shot 5 — Flag Review (20s)
- Click on the flag
- Click Dismiss
- Show the status change

## Shot 6 — Management Dashboard (45s)
- Login as management
- Show `/management` with VNEI by zone
- Hover over zone cards to show coverage
- Point out the k<5 suppressed zone
- Point out "Sample data" labels on mock sections

## Shot 7 — Student Self-View (30s)
- Login as student
- Show `/me` heat strip and history
- Show consent panel
- Show "Delete my data" button (don't submit)

## Shot 8 — Enrollment (45s)
- Login as admin
- Navigate to `/enrollment`
- Search for a student
- Drag a video file into the upload zone
- Show the result (or explain the flow)

## Editing Notes
- Use OBS Studio or similar screen recorder
- Record at 1080p, browser full-screen
- Add captions for each section
- Export as MP4, keep under 100MB
- Store on USB drive as backup for demo day
